# LogicComm: a relative-expression-ordering framework for interpretable and sample-level cell-cell communication analysis in single-cell RNA-seq

LogicComm Developer

Correspondence: dev@logiccomm.io

## Abstract

Single-cell transcriptomics has enabled systematic inference of ligand-receptor communication, but many workflows depend on cross-sample normalization, pre-defined cell-type matching, or cell-pooled comparisons that can be difficult to interpret in cohort studies. LogicComm is an R package that converts each cell into a within-cell relative expression ordering binary state and summarizes ligand-receptor activity as Logic Consensus Scores. The framework scores communication at the cell-type level from REO co-expression: for each sender and receiver cell-type pair, the Logic Consensus Score is the fraction of the pair's opportunity universe (the sender-by-receiver cell-count product) in which the ligand logic is active in the sender cell and the receptor logic is active in the receiver cell. It adds cell-type-resolved sender-receiver summaries, signaling-role interpretation, specificity and proliferation/transcriptional-breadth confound diagnostics, permutation-null and bootstrap uncertainty, and sample-level Case versus Control comparison. Because dissociated scRNA-seq carries no physical-distance information, LogicComm deliberately does not aggregate over a per-cell neighborhood graph and makes no spatial juxtacrine/paracrine distance claims. We evaluated LogicComm on the PBMC3K dataset and on a four-sample PBMC-derived simulation in which PBMC3K was split into `pbmc1`, `pbmc2`, `pbmc3`, and `pbmc4`, with controlled Case perturbations introduced into `pbmc1` and `pbmc2`. In the single-sample PBMC3K workflow, LogicComm produced sparse REO states, recovered expected immune communication axes such as MIF, MHC-I, and galectin-related interactions, filtered missing cell-type labels, and generated cell-type network, heatmap, bubble, and role-summary plots. In the four-sample simulation, five targeted ligand-receptor axes were active in both Case samples and inactive in both Control samples at the selected validation threshold, demonstrating correct sample alignment and recovery of known perturbations. LogicComm is designed as a transparent, extensible, and publication-oriented complement to existing cell-cell communication methods, with explicit caution that small simulated examples validate software behavior but do not provide powered biological inference.

## Introduction

Cell-cell communication inference has become a central component of single-cell RNA-seq analysis because many cellular phenotypes are driven not only by intrinsic transcriptional programs but also by ligand-receptor interactions across functionally connected populations. Widely used frameworks such as CellPhoneDB, CellChat, NicheNet, and LIANA have established ligand-receptor databases, probability models, downstream target inference, and consensus workflows for interpreting intercellular signaling from single-cell data. These methods have substantially advanced the field, but practical challenges remain when investigators need to compare multiple biological samples, handle sparse expression, preserve sample-level replication, separate broad or identity-associated axes from cell-type-pair-specific candidates, and communicate results with enough diagnostic context for publication.

LogicComm addresses these needs by using relative expression ordering as the first transformation step. Rather than comparing absolute expression levels across cells or samples, each cell is converted into a binary logic state indicating whether a gene is active relative to that cell's own expression anchor. This design is motivated by the observation that within-sample relative expression orderings can be robust to batch effects and scale differences, while still preserving biologically interpretable rank states. In LogicComm, ligand-receptor activity is then summarized by REO co-expression: the fraction of opportunities in which the ligand logic is active in a sender cell and the receptor logic is active in a receiver cell. In the single-sample setting this is the cell-level co-expression fraction; in the cell-type-resolved setting it is computed per sender-receiver cell-type pair over the sender-by-receiver opportunity universe. LogicComm scores communication at the cell-type (or global) level and does not aggregate over a per-cell nearest-neighbor graph: for dissociated scRNA-seq such a graph reflects transcriptomic similarity in expression space rather than physical proximity, so it cannot license spatial juxtacrine or paracrine distance claims.

The package is intended for both single-sample discovery and cohort-level analysis. In a single sample, LogicComm helps prioritize ligand-receptor pairs, identify communication-active cells, and interpret sender-receiver cell-type relationships. In a cohort, LogicComm treats each biological sample as the unit of comparison and compares sample-level LCS vectors across Case and Control groups. This distinction is important because pooling cells across patients can create pseudo-replication and inflate apparent precision. LogicComm therefore emphasizes explicit sample names, group labels, per-sample REO/LCS computation, and comparison outputs that report sample availability, active frequency, effect direction, and adjusted p-values.

## Methods

LogicComm accepts base matrices, sparse Matrix objects, Seurat objects, and BPCells on-disk matrices. Expression inputs are interpreted as genes by cells. The `calc_REO_matrix()` function computes within-cell anchors from all available genes by default and returns binary logic states only for retained ligand-receptor genes. This separation allows the rank anchor universe to remain stable while the output gene set is controlled by the selected ligand-receptor database. An optional cell-type-free ambient guard additionally requires each gene to exceed its own across-cell background, removing ambient or dropout counts that clear the within-cell anchor. Complex ligands or receptors are represented by list columns of gene symbols, and the current default logic requires all listed subunits to be active for the complex to be active.

The core ligand-receptor score is the Logic Consensus Score (LCS). In the single-sample global setting it is the proportion of cells that co-express the complete ligand logic and the complete receptor logic. In the cell-type-resolved setting, for each directed sender-to-receiver cell-type pair it is the fraction of the pair's opportunity universe — the product of the number of sender cells and the number of receiver cells — in which the ligand is active in the sender cell and the receptor is active in the receiver cell; equivalently, the product of the ligand-active fraction among sender cells and the receptor-active fraction among receiver cells. An optional rank weighting replaces the binary co-expression fraction with a prevalence-weighted within-cell REO rank, which preserves the prevalence signal that separates specific from ubiquitous axes while adding dynamic range. With `include_self = TRUE` (the default), same-cell-type sender-receiver pairs are retained and interpreted as homotypic or autocrine-like population-level potential. Cell labels are aligned to REO cell order, and cells with missing or empty labels are reported and filtered rather than silently misassigned.

Cell-type communication summaries are generated by `summarize_celltype_communication()`. This function resolves cell labels, filters missing or empty labels with an explicit message, computes ligand and receptor activity by sender and receiver type, and scores each directed cell-type pair as described above. Outputs include an LR-level table, sender-receiver pair summaries, pathway summaries, adjacency matrices, cell-type sizes, and signaling-role summaries. Role summaries include outgoing and incoming strength, betweenness-based mediator scores that use inverse communication strength as the edge distance, PageRank-based influencer scores, event counts, confidence labels, and biological interpretation fields. Plotting helpers generate cell-type heatmaps, network views, LR bubble plots, pathway heatmaps, role plots, and publication-oriented specificity diagnostics. A one-call `discover_celltype_communication()` pipeline chains scoring, specificity and proliferation/transcriptional-breadth confound annotation, an axis-level permutation null with Benjamini-Hochberg control, evidence ranking, and a confound-filtered discovery view.

Multi-sample analysis is performed with either explicit per-sample calls or the `run_multisample()` wrapper. The wrapper computes REO and LCS for each named sample, excludes failed samples with warnings, and passes the resulting LCS vectors to `CompareLogicGroups()`. The comparison table reports Case and Control active frequencies, mean LCS values, log2 fold changes, Fisher and Wilcoxon p-values, Benjamini-Hochberg adjusted values, total group sizes, and per-pair non-missing sample counts. Missing LCS values are treated as unavailable rather than negative calls. This behavior is intended to keep the biological sample as the statistical unit and to make low-resolution comparisons transparent.

## PBMC3K single-sample validation

_Note: the PBMC3K and four-sample figures reported below were produced with a pre-v0.13 build that still offered per-cell neighborhood scoring. They are retained to illustrate the workflow and should be regenerated against the v0.13 cell-type co-expression scorer before submission; cell-type LCS values and active-event counts will differ, and the former neighborhood / communication-range fields no longer exist._

We evaluated the package on the PBMC3K dataset distributed through SeuratData. The workflow loaded 2700 cells and 13,714 genes, performed standard Seurat preprocessing, converted the raw counts into REO states, and scored the built-in compact human ligand-receptor database. The REO matrix contained 123 retained genes by 2700 cells, with 14,399 active entries. Cell-type communication analysis used the Seurat annotation column when available and filtered cells with missing or empty labels before summarization. The recovered axes were dominated by MIF, MHC-I, and galectin-related interactions — for example MIF_CD74, HLA-A_CD8A, HLA-B_CD8A, LGALS3_CD44, and MIF_CD44 — among dendritic-cell, monocyte, CD8 T-cell, B-cell, and memory CD4 T-cell populations, consistent with expected PBMC immune signaling. Cell-level communication scoring returned sender, receiver, and combined activity vectors without missing metadata after alignment to the Seurat cell order. Plotting helpers for cell-type networks, role positioning, role heatmaps, advanced LR bubbles, clustered pathway heatmaps, and pathway dominance all returned valid ggplot objects.

## PBMC-derived four-sample simulation

To validate multi-sample behavior with PBMC-derived data, we created an executable demonstration that splits PBMC3K into four sample-level matrices named `pbmc1`, `pbmc2`, `pbmc3`, and `pbmc4`. The first two matrices are assigned to the simulated Case group, and the latter two are assigned to the simulated Control group. A controlled perturbation is introduced into `pbmc1` and `pbmc2` by increasing MIF, CD74, LGALS3, CD44, HLA-A, and CD8A counts. The perturbation intentionally targets axes that are biologically plausible in PBMC data and present in the built-in ligand-receptor database, while preserving the fact that this is a software validation and not a disease study.

Using `seed = 20260526`, `perturb_lambda = 50`, and `lcs_threshold = 0.2`, LogicComm recovered five targeted Case-enriched axes. MIF_CD44, HLA-A_CD8A, HLA-B_CD8A, LGALS3_CD44, and MIF_CD74 each had Case active frequency of 1, Control active frequency of 0, and asymmetry of 1. Their log2 LCS fold changes were 5.3543, 4.7840, 4.5520, 4.5161, and 3.5407, respectively. Fisher-adjusted values were 1 because the demonstration uses only two samples per group, which makes the minimum attainable p-value too coarse for publication-level inference. The result verifies sample naming, group alignment, REO/LCS response to known perturbation, and sample-level comparison mechanics. The complete executable script is included as `inst/examples/pbmc_multisample_demo.R`, and the companion vignette is `vignettes/PBMC_multisample_demo.Rmd`.

The package test suite covers REO anchoring, the cell-type-free ambient guard, chunked sparse computation, ligand-receptor scoring, cell-type co-expression summaries, rank-weighted scoring, missing-label filtering, axis-level permutation nulls and bootstrap intervals, the proliferation/transcriptional-breadth confound diagnostic, specificity scoring and the confound-filtered discovery view, plotting helpers, spatial and pseudotime extensions, sample-level GLMs, the four-sample PBMC-style multi-sample perturbation, and regression tests added by the communication-correctness audit (mediator betweenness orientation, single-cell-type role stability, ligand-receptor identifier uniqueness, per-cell ranking label alignment, and sample-level differential-communication count construction). In the current validation run, the test suite completed with 75 passing `test_that` blocks, no failures, and no errors, and `R CMD check` reported no code or documentation problems under a UTF-8 locale, with only the expected note that suggested packages (Seurat, SeuratObject, pheatmap, BPCells) were not installed in the offline build environment. Final checks should be repeated after any manuscript, vignette, or example change.

## Discussion

LogicComm contributes a logic-state interpretation layer for cell-cell communication analysis. Its main distinction is not a new ligand-receptor database but a scoring strategy that starts from within-cell rank states and keeps sample-level replication explicit. This approach is useful when investigators need a transparent, reproducible workflow for comparing multiple scRNA-seq samples without treating every cell as an independent biological replicate. The PBMC3K analysis illustrates the single-sample workflow, while the PBMC1-4 simulation demonstrates the multi-sample validation path with a known expected signal.

The framework is complementary to established tools rather than a replacement. CellPhoneDB, CellChat, NicheNet, and LIANA provide rich databases, statistical models, downstream target modeling, and consensus resources. LogicComm is designed to integrate with this ecosystem by accepting custom ligand-receptor tables and by emphasizing interpretable REO/LCS states, cell-type co-expression evidence, sender-receiver cell-type summaries, and publication-oriented diagnostics. For example, a broad MHC or MIF signal in PBMC data may be biologically real but not mechanistically specific; LogicComm reports specificity, proliferation/transcriptional-breadth confound, and role diagnostics to help users separate stable broad immune-recognition axes from more pair-specific communication candidates.

Several limitations should be considered. The compact built-in ligand-receptor database is intended as a seed set and should be replaced or expanded when comprehensive pathway coverage is needed. REO threshold choices affect binary activity calls, so sensitivity analysis across thresholds is recommended. Cell-type co-expression LCS quantifies population-level co-expression potential, not physical contact or directional causality; because dissociated scRNA-seq has no physical-distance information, LogicComm makes no spatial juxtacrine or paracrine distance claims, and spatial questions require spatially resolved data and a dedicated spatial scorer. Same-cell-type communication should be interpreted as homotypic or autocrine-like population-level potential, not proof that the same single cell secreted and received a ligand. Finally, the PBMC1-4 simulation validates software behavior but is not statistically powered; real cohort claims require independent biological samples, covariate-aware models when appropriate, and orthogonal biological validation.

## Conclusion

LogicComm provides a reproducible R framework for logic-based ligand-receptor scoring, cell-type-resolved interpretation, and sample-level multi-sample comparison in single-cell RNA-seq studies. By combining relative expression ordering, cell-type co-expression LCS scoring, explicit sample-level comparison, and publication-oriented diagnostics, the package helps convert ligand-receptor activity into interpretable hypotheses while making important limitations visible. The PBMC3K and PBMC1-4 demonstrations show that the workflow can be executed on familiar immune single-cell data and that known sample-level perturbations are recovered in the expected direction.
