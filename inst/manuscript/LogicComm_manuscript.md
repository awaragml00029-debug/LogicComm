# LogicComm: a relative-expression-ordering framework for interpretable and sample-level cell-cell communication analysis in single-cell RNA-seq

LogicComm Developer

Correspondence: dev@logiccomm.io

## Abstract

Single-cell transcriptomics has enabled systematic inference of ligand-receptor communication, but many workflows depend on cross-sample normalization, pre-defined cell-type matching, or cell-pooled comparisons that can be difficult to interpret in cohort studies. LogicComm is an R package that converts each cell into a within-cell relative expression ordering binary state and summarizes ligand-receptor activity as Logic Consensus Scores. The framework supports global scoring, neighborhood-aware scoring with Seurat KNN/SNN or user-supplied graphs, cell-type-resolved sender-receiver summaries, signaling-role interpretation, uncertainty diagnostics, and sample-level Case versus Control comparison. We evaluated LogicComm on the PBMC3K dataset and on a four-sample PBMC-derived simulation in which PBMC3K was split into `pbmc1`, `pbmc2`, `pbmc3`, and `pbmc4`, with controlled Case perturbations introduced into `pbmc1` and `pbmc2`. In the single-sample PBMC3K workflow, LogicComm produced sparse REO states, recovered expected immune communication axes such as MIF, MHC-I, and galectin-related interactions, filtered missing cell-type labels, and generated cell-type network, heatmap, bubble, and role-summary plots. In the four-sample simulation, five targeted ligand-receptor axes were active in both Case samples and inactive in both Control samples at the selected validation threshold, demonstrating correct sample alignment and recovery of known perturbations. LogicComm is designed as a transparent, extensible, and publication-oriented complement to existing cell-cell communication methods, with explicit caution that small simulated examples validate software behavior but do not provide powered biological inference.

## Introduction

Cell-cell communication inference has become a central component of single-cell RNA-seq analysis because many cellular phenotypes are driven not only by intrinsic transcriptional programs but also by ligand-receptor interactions across neighboring or functionally connected populations. Widely used frameworks such as CellPhoneDB, CellChat, NicheNet, and LIANA have established ligand-receptor databases, probability models, downstream target inference, and consensus workflows for interpreting intercellular signaling from single-cell data. These methods have substantially advanced the field, but practical challenges remain when investigators need to compare multiple biological samples, handle sparse expression, preserve sample-level replication, distinguish local graph-supported evidence from global signaling potential, and communicate results with enough diagnostic context for publication.

LogicComm addresses these needs by using relative expression ordering as the first transformation step. Rather than comparing absolute expression levels across cells or samples, each cell is converted into a binary logic state indicating whether a gene is active relative to that cell's own expression anchor. This design is motivated by the observation that within-sample relative expression orderings can be robust to batch effects and scale differences, while still preserving biologically interpretable rank states. In LogicComm, ligand-receptor activity is then summarized by the fraction of opportunities in which the ligand logic is active in a sender cell and the receptor logic is active in a receiver cell. When a KNN, SNN, or spatial graph is supplied, the score describes local neighborhood-supported communication. When no graph is supplied, the same logic is used to estimate global cell-level or cell-type-level communication potential.

The package is intended for both single-sample discovery and cohort-level analysis. In a single sample, LogicComm helps prioritize ligand-receptor pairs, identify communication-active cells, and interpret sender-receiver cell-type relationships. In a cohort, LogicComm treats each biological sample as the unit of comparison and compares sample-level LCS vectors across Case and Control groups. This distinction is important because pooling cells across patients can create pseudo-replication and inflate apparent precision. LogicComm therefore emphasizes explicit sample names, group labels, per-sample REO/LCS computation, and comparison outputs that report sample availability, active frequency, effect direction, and adjusted p-values.

## Methods

LogicComm accepts base matrices, sparse Matrix objects, Seurat objects, optional Seurat KNN/SNN graphs, and user-supplied adjacency matrices. Expression inputs are interpreted as genes by cells. The `calc_REO_matrix()` function computes within-cell anchors from all available genes by default and returns binary logic states only for retained ligand-receptor genes. This separation allows the rank anchor universe to remain stable while the output gene set is controlled by the selected ligand-receptor database. Complex ligands or receptors are represented by list columns of gene symbols, and the current default logic requires all listed subunits to be active for the complex to be active.

The core ligand-receptor score is the Logic Consensus Score. For global scoring, the score is the proportion of cells or cell-type opportunities in which ligand and receptor logic are jointly satisfied. For neighborhood scoring, LogicComm extracts graph edges from a Seurat object or accepts a cells-by-cells adjacency matrix. Self-loop cell-level edges are removed by default to avoid interpreting within-cell ligand-receptor co-activity as direct intercellular communication, while same-cell-type sender-receiver pairs are retained and interpreted as homotypic or autocrine-like communication potential. Named graph matrices are aligned to REO cell order, and missing cells trigger an error rather than silent misalignment.

Cell-type communication summaries are generated by `summarize_celltype_communication()`. This function resolves cell labels, filters missing or empty labels with an explicit message, computes ligand and receptor activity by sender and receiver type, and reports both local and global evidence. Outputs include an LR-level table, sender-receiver pair summaries, pathway summaries, adjacency matrices, cell-type sizes, and signaling-role summaries. Role summaries include outgoing and incoming strength, betweenness-like mediator scores, eigen-centrality-like influencer scores, event counts, confidence labels, and biological interpretation fields. Plotting helpers generate cell-type heatmaps, network views, signaling range summaries, LR bubble plots, pathway heatmaps, role plots, and publication-oriented specificity diagnostics.

Multi-sample analysis is performed with either explicit per-sample calls or the `run_multisample()` wrapper. The wrapper computes REO and LCS for each named sample, excludes failed samples with warnings, and passes the resulting LCS vectors to `CompareLogicGroups()`. The comparison table reports Case and Control active frequencies, mean LCS values, log2 fold changes, Fisher and Wilcoxon p-values, Benjamini-Hochberg adjusted values, total group sizes, and per-pair non-missing sample counts. Missing LCS values are treated as unavailable rather than negative calls. This behavior is intended to keep the biological sample as the statistical unit and to make low-resolution comparisons transparent.

## PBMC3K single-sample validation

We first evaluated the package on the PBMC3K dataset distributed through SeuratData. The workflow loaded 2700 cells and 13,714 genes, performed standard Seurat preprocessing, generated RNA nearest-neighbor and shared-nearest-neighbor graphs, converted the raw counts into REO states, and scored the built-in compact human ligand-receptor database. The REO matrix contained 123 retained genes by 2700 cells, with 14,399 active entries. Neighborhood LCS scoring on the RNA nearest-neighbor graph produced 109 ligand-receptor scores, of which 43 were finite and 13 were positive. The strongest PBMC3K axes included MIF_CD74, HLA-A_CD8A, HLA-B_CD8A, LGALS3_CD44, MIF_CD44, LGALS1_CD69, and HLA-DRA_CD4. The RNA nearest-neighbor and RNA shared-nearest-neighbor sensitivity comparison yielded a correlation of 0.9992 for complete ligand-receptor scores, indicating that the strongest signals in this PBMC3K workflow were robust to these two graph definitions.

Cell-level communication scoring returned sender, receiver, and combined activity vectors without missing metadata after alignment to the Seurat cell order. Cell-type communication analysis used the Seurat annotation column when available and filtered 62 cells with missing or empty labels before summarization. The resulting cell-type communication object contained 3483 LR rows, 322 active LR events, 81 sender-receiver pair rows, and nine same-cell-type sender-receiver pairs. The strongest pair summaries were dominated by dendritic-cell, monocyte, CD8 T-cell, B-cell, and memory CD4 T-cell relationships, with communication ranges classified as paracrine or distal/endocrine depending on the relation between local and global evidence. Plotting helpers for range summaries, cell-type networks, role positioning, role heatmaps, advanced LR bubbles, clustered pathway heatmaps, and pathway dominance all returned valid ggplot objects.

## PBMC-derived four-sample simulation

To validate multi-sample behavior with PBMC-derived data, we created an executable demonstration that splits PBMC3K into four sample-level matrices named `pbmc1`, `pbmc2`, `pbmc3`, and `pbmc4`. The first two matrices are assigned to the simulated Case group, and the latter two are assigned to the simulated Control group. A controlled perturbation is introduced into `pbmc1` and `pbmc2` by increasing MIF, CD74, LGALS3, CD44, HLA-A, and CD8A counts. The perturbation intentionally targets axes that are biologically plausible in PBMC data and present in the built-in ligand-receptor database, while preserving the fact that this is a software validation and not a disease study.

Using `seed = 20260526`, `perturb_lambda = 50`, and `lcs_threshold = 0.2`, LogicComm recovered five targeted Case-enriched axes. MIF_CD44, HLA-A_CD8A, HLA-B_CD8A, LGALS3_CD44, and MIF_CD74 each had Case active frequency of 1, Control active frequency of 0, and asymmetry of 1. Their log2 LCS fold changes were 5.3543, 4.7840, 4.5520, 4.5161, and 3.5407, respectively. Fisher-adjusted values were 1 because the demonstration uses only two samples per group, which makes the minimum attainable p-value too coarse for publication-level inference. The result verifies sample naming, group alignment, REO/LCS response to known perturbation, and sample-level comparison mechanics. The complete executable script is included as `inst/examples/pbmc_multisample_demo.R`, and the companion vignette is `vignettes/PBMC_multisample_demo.Rmd`.

## Software verification

The package test suite covers REO anchoring, chunked sparse computation, ligand-receptor scoring, KNN self-loop removal, weighted graph scoring, cell-type summaries, missing label filtering, permutation nulls, adaptive permutation progress messages, plotting helpers, spatial and pseudotime extensions, sample-level GLMs, and the four-sample PBMC-style multi-sample perturbation. In the current validation run, `pkgload::load_all()` succeeded and `testthat::test_dir("tests/testthat")` completed with 181 passing tests, no failures, no warnings, and no skips. The package also passed source build and package check before the PBMC multi-sample documentation additions, and final checks should be repeated after any manuscript, vignette, or example change.

## Discussion

LogicComm contributes a logic-state interpretation layer for cell-cell communication analysis. Its main distinction is not a new ligand-receptor database but a scoring strategy that starts from within-cell rank states and keeps sample-level replication explicit. This approach is useful when investigators need a transparent, reproducible workflow for comparing multiple scRNA-seq samples without treating every cell as an independent biological replicate. The PBMC3K analysis illustrates the single-sample workflow, while the PBMC1-4 simulation demonstrates the multi-sample validation path with a known expected signal.

The framework is complementary to established tools rather than a replacement. CellPhoneDB, CellChat, NicheNet, and LIANA provide rich databases, statistical models, downstream target modeling, and consensus resources. LogicComm is designed to integrate with this ecosystem by accepting custom ligand-receptor tables and by emphasizing interpretable REO/LCS states, graph-supported evidence, sender-receiver cell-type summaries, and publication-oriented diagnostics. For example, a broad MHC or MIF signal in PBMC data may be biologically real but not mechanistically specific; LogicComm reports specificity, range, and role diagnostics to help users separate stable broad immune-recognition axes from more pair-specific communication candidates.

Several limitations should be considered. The compact built-in ligand-receptor database is intended as a seed set and should be replaced or expanded when comprehensive pathway coverage is needed. REO threshold choices affect binary activity calls, so sensitivity analysis across thresholds is recommended. KNN or SNN graph-based inference describes proximity in transcriptomic manifold space, not necessarily physical contact. Same-cell-type communication should be interpreted as homotypic or autocrine-like population-level potential, not proof that the same single cell secreted and received a ligand. Finally, the PBMC1-4 simulation validates software behavior but is not statistically powered; real cohort claims require independent biological samples, covariate-aware models when appropriate, and orthogonal biological validation.

## Conclusion

LogicComm provides a reproducible R framework for logic-based ligand-receptor scoring, cell-type-resolved interpretation, and sample-level multi-sample comparison in single-cell RNA-seq studies. By combining relative expression ordering, optional graph-supported LCS scoring, explicit sample-level comparison, and publication-oriented diagnostics, the package helps convert ligand-receptor activity into interpretable hypotheses while making important limitations visible. The PBMC3K and PBMC1-4 demonstrations show that the workflow can be executed on familiar immune single-cell data and that known sample-level perturbations are recovered in the expected direction.
